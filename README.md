# Personal Expense Tracker

A beginner-friendly expense tracking application built with HTML, CSS and JavaScript.

## Live Demo
https://susankimathi637-max.github.io/personal-expense-tracker/

## Features
- Record income and expenses
- Automatically calculate total income, total expenses and remaining balance
- View a transaction history, with income in green and expenses in red

## Technologies Used
- HTML
- CSS
- JavaScript

## Why I Built This
I studied Business Management (Accounting) and wanted to apply my understanding of income, expenses and balances to solve an everyday financial problem using code. This is my first programming project.

## What I Learned
- Structuring a web page with HTML
- Styling with CSS
- Using JavaScript to handle user input and calculations
- Publishing a project with GitHub and GitHub Pages
